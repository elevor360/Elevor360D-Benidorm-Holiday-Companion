Elevor360D Benidorm V4 - Universal Advertising Manager V1 compatibility

Upload all files and folders to the Benidorm GitHub Pages repository, preserving folder paths.

To update adverts using your working Universal Advertising Manager V1:
1. Create/edit adverts and set Destination category to Holiday Companions or All participating apps (or Specific app IDs: benidorm-companion).
2. Click Download adverts.json, and Download Images.
3. Upload adverts.json to advertising/adverts.json in this app repository.
4. Upload each downloaded image into advertising/images/ with its exact filename.
5. Refresh the app online; changes are checked on launch and approximately every 30 minutes while open. Offline the last cached adverts may show.

The original guide advert section remains unchanged. This version adds a separate rotating banner above the guide menu. Example banner can be replaced by your exported file.

NOTE: Manager V1 exports files; it does not publish to GitHub automatically. Existing app data is stored on the device; keep a backup before updating.
