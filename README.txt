ELEVOR360D BENIDORM HOLIDAY COMPANION V1

CUSTOMER APP: Upload index.html, guide.json, manifest.webmanifest, sw.js, icon-192.png, icon-512.png and adverts/ folder to the root of a PUBLIC GitHub Pages repository. Set Pages to Deploy from branch / root. Open the HTTPS Pages URL.

MANAGER: Open guide-manager.html locally in Chrome. Import your CURRENT guide.json, edit, then download the new guide.json and replace the file in GitHub. The manager does not edit GitHub directly. Keep the manager file private if you prefer; it is not needed for the public app.

ADVERTS: Add adverts/advert.jpg to GitHub, enable it and set adverts/advert.jpg in the manager, export guide.json.

OFFLINE: Visit once online and allow caching. Personal data stays in browser storage on that device. Use Backup/Restore when switching devices or clearing browser data. Live links, external QR service and online information need internet.

INSTALL: Browser controls the native install prompt. On Android Chrome, use menu > Add to Home screen / Install app if needed. On iPhone Safari use Share > Add to Home Screen.

Guide is a starter overview, not live opening hours, prices or transport schedules. Verify details before travel.
